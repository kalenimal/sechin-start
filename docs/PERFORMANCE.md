## Что ещё можно сделать

- **Страница проекта (LCP 3.5 с).** Данные берутся из `localStorage` на клиенте, поэтому обложка появляется только после загрузки JS и мок-запроса. С реальным API запрос стоит перенести в server component (или prefetch через `HydrationBoundary`), тогда обложка придёт в HTML.
- **zod v4** — самая тяжёлая зависимость форм. Если важны килобайты, можно перейти на `zod/mini`.
- **Шрифт:** сейчас 3 начертания × 2 сабсета. Можно отказаться от одного начертания или включить variable-шрифт.

## Как перемерить

```bash
npm run build && npx next start -p 3200
npx lighthouse@12 http://localhost:3200/ --chrome-flags="--headless=new" --view
# страницы кабинета — с cookie сессии:
# --extra-headers='{"Cookie":"sp_session=<encodeURIComponent(JSON сессии)>"}'
```
