# Соглашения

## Код

- TypeScript strict, без `any`. Типы домена живут в `entities/*/model/types.ts`.
- Форматирование — Prettier (`npm run format`), линт — ESLint `next/core-web-vitals` + `next/typescript`.
- `npm run check` = typecheck + lint + format:check. Запускайте перед коммитом.
- Компоненты именованные (`export function`), один компонент на файл, рядом его `*.module.css`.
- Клиентские компоненты помечены `'use client'`; серверные страницы остаются серверными, интерактив выносится вниз по дереву.
- Комментарии объясняют «почему», а не «что».

## Стили

- CSS Modules и токены из `globals.css`. Хардкод цветов допустим только для разовых оттенков, которых нет в токенах.
- Сначала десктоп, затем `@media (max-width: 1024px / 640px)` и `@media (max-height: 860px)` для невысоких экранов.
- **Не используйте `minmax(0, 1fr)` для одной колонки:** Lightning CSS (Turbopack) при минификации превращает его в `1fr`, и длинный текст ломает сетку. Используйте `100%`.
- Анимации — только через токены `--duration-*` и `--ease-*`. Глобальный `prefers-reduced-motion` их отключает.

## Формы

- react-hook-form + zod; общие схемы в `shared/lib/validation`.
- Асинхронные действия — через `useAsyncAction`: `run()` возвращает `{ ok, data } | { ok: false, error }` и никогда не бросает.
- Обратная связь после успешной мутации — `toast.success(...)`.

## Данные

- Компоненты не обращаются к `localStorage` или `fetch` напрямую, только через хуки сущностей.
- Новая сущность: `model/types.ts`, `model/mock.ts`, `api/*Api.ts` (функции + хуки + ключи), `ui/*`, `index.ts`.

## Маршруты

- Все пути строятся через `routes` из `shared/config/routes.ts`, строковые литералы URL в компонентах не пишем.
