# UI-kit (`src/shared/ui`)

Компоненты повторяют страницу **UI KIT** из Figma. Стили сделаны на CSS Modules и токенах из `src/app/globals.css`.
Импорт идёт из публичного API: `import { Button, TextField } from '@/shared/ui'`.

## Токены

| Группа      | Переменные                                                                                                                                                                                             |
| ----------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------ |
| Цвета       | `--color-primary` `#387184` (+ `-5`, `-10`, `-40`), `--color-secondary` `#d64933`, `--color-red`, `--color-black`, `--color-dark-grey`, `--color-grey`, `--color-background`, `--color-white(-50/-40)` |
| Типографика | `--fs-h1..h6` (48→20), `--fs-paragraph` 17, `--fs-caption` 15, `--fs-small` 12; `--lh-title` 1.1, `--lh-text` 1.3; `--tracking` −0.02em                                                                |
| Радиусы     | `--radius-s` 5, `--radius-m` 10, `--radius-l` 20                                                                                                                                                       |
| Движение    | `--ease-out`, `--ease-in-out`, `--duration-fast/base/slow`; анимации `fade-in`, `fade-up`, `scale-in`, `pop`, `grow-x/y`, `shake`                                                                      |

Шрифт — IBM Plex Sans (400/500/600, latin + cyrillic) через `next/font`. Минимальный размер текста в интерфейсе — 12px.

## Компоненты

### Действия

| Компонент    | Описание                                                                                                                                                                                                    |
| ------------ | ----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| `Button`     | `color`: `primary`, `secondary`, `white`, `white50`, `grey`; `size`: `l` 60 / `m` 48 / `s` 40 / `xs` 32; `iconLeft`, `iconRight`, `iconOnly`, `fullWidth`, `loading`. При `href` рендерится как `next/link` |
| `TextLink`   | полужирная текстовая ссылка или кнопка («Забыли пароль?»); `align`, `size`, `tone`, `icon`                                                                                                                  |
| `MenuButton` | пункт сайдбара: иконка 42×42, активное состояние, бейдж                                                                                                                                                     |

### Поля ввода

| Компонент            | Описание                                                                                                    |
| -------------------- | ----------------------------------------------------------------------------------------------------------- |
| `TextField`          | label + `*`, `error`, `hint`, `endAdornment`; `forwardRef` для `register()`                                 |
| `Textarea`           | многострочное поле в том же стиле                                                                           |
| `PhoneField`         | маска `+7 900 900 00 00`, контролируемое (`value` / `onChange`)                                             |
| `Select`             | `variant="field"` (форма) или `"filter"` («Статус проекта: Все»), счётчики в опциях, навигация с клавиатуры |
| `MultiSelect`        | множественный выбор, выбранное выводится через запятую                                                      |
| `Checkbox` / `Radio` | 24px, красное состояние «вкл»                                                                               |
| `RadioGroup`         | `layout="grid"` (2 колонки) или `"row"`                                                                     |
| `ChoiceChips`        | множественный выбор чипами с чекбоксом (фильтры)                                                            |
| `RangeField`         | пара «От ₽ / До ₽» с разбивкой разрядов                                                                     |
| `SearchInput`        | поиск с кнопкой очистки                                                                                     |
| `CodeInput`          | 6 ячеек OTP, вставка из буфера, стрелки, тряска при ошибке                                                  |
| `FileUpload`         | dashed-dropzone и плитки файлов с удалением, лимиты размера и количества                                    |
| `ImageUpload`        | обложка или логотип с превью и меню «Изменить / Удалить»                                                    |

### Оверлеи и обратная связь

| Компонент           | Описание                                                                                              |
| ------------------- | ----------------------------------------------------------------------------------------------------- |
| `Modal`             | портал, Esc и клик по фону закрывают, фокус возвращается, блокировка скролла, анимация входа и выхода |
| `Toaster` + `toast` | `toast.success / error / info('…')`, автоскрытие через 3.5 с, максимум 3 одновременно                 |

## Доступность

- У полей есть `label` / `aria-describedby`, ошибки помечены `role="alert"`.
- `Select` реализует паттерн listbox (стрелки, Home/End, Enter, Esc).
- Модалки: `role="dialog"`, `aria-modal`, фокус и Esc.
- У графика есть визуально скрытая таблица данных.
- `prefers-reduced-motion` отключает анимации глобально.
